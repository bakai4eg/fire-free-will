# Versions

The site (`main`) is **v11**: one-screen tool with a 3D globe, search for any place, click a country,
drag to move / wheel or pinch to zoom, live last 7 days worldwide, "now vs normal", fire danger for 3 days,
villages near fires in Kyrgyzstan, burning calendar 2001–2025 from harmonized MODIS + VIIRS.

Earlier iterations from the night of 15 Nov 2026 are kept as git tags `v1` … `v10` (not hosted any more).
To look at one locally: `git checkout v8 && python -m http.server 8000 -d web`.
